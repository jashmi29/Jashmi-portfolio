# Styles

Global styles live in `app/globals.css` (imported by the root layout).

The design system is built on CSS custom properties (HSL color tokens),
Tailwind CSS utility classes, and a set of reusable utility classes:

- `.glass` / `.glass-strong` — glassmorphism surfaces
- `.gradient-border` — animated gradient borders
- `.mesh-bg` — layered mesh-gradient background
- `.noise-overlay` — fine grain texture
- `.text-gradient-primary` — animated gradient text
- `.shadow-soft` / `.shadow-lift` / `.shadow-glow` — soft shadow system
